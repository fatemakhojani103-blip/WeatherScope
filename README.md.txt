# WeatherScope Linux Project

## Introduction
WeatherScope is a Linux-based project developed using Shell Scripting.

## Project Files
- setup_weatherscope.sh
- data
- screenshots

## Technologies Used
- Linux
- Bash Shell Scripting
- Git
- GitHub

## How to Run

1. Open Git Bash.
2. Navigate to the WeatherScope folder.
3. Run:

chmod +x setup_weatherscope.sh

4. Execute:

./setup_weatherscope.sh
